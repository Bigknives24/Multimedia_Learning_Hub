# Multimedia Learning Hub

## About the Project

The Multimedia Learning Hub is an educational website designed to provide students with easy access to multimedia learning materials.

The platform provides educational content through HTML5 audio and video lectures, downloadable learning resources, and information about the learning hub.

## Features

- Audio lecture section
- Video lecture section
- Educational resources
- About section
- Simple and user-friendly navigation
- HTML5 audio and video integration
- Responsive web design

## Technologies Used

- HTML5
- CSS3

## Pages

- Home
- Audio Lectures
- Video Lectures
- Resources
- About

## Purpose

The purpose of this project is to create a centralized multimedia learning platform that allows students, particularly remote learners, to access educational materials conveniently.
